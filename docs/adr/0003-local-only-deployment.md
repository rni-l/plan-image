# ADR 0003：第一版仅在单台电脑本地运行

- 状态：已接受
- 日期：2026-08-01

## 背景

系统只有一个用户，不需要跨设备访问、团队共享或云端服务。

## 决策

第一版作为当前电脑上的本地网页系统运行，通过浏览器访问。业务数据、设置、上传素材和生成结果默认保存在本机。系统不提供公网服务或局域网访问，也不使用 Electron、Tauri 等桌面应用封装。

模型分析与生成仍可通过网络调用用户在设置页配置的外部 API。

## 影响

- 不需要服务器账号体系和多租户隔离。
- 需要明确本地数据目录、容量管理、导出和备份方式。
- API 密钥必须使用适合本机应用的安全存储方式，不能明文写入项目文件或前端代码。
- 不需要针对特定桌面操作系统制作安装包。
- 第一版通过一个启动命令运行本地前后端，不制作操作系统安装包。
