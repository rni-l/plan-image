# ADR 0004：采用端到端位图生成与 AI 局部微调

- 状态：已接受
- 日期：2026-08-01

## 背景

候选路线包括端到端整图生成、模板化图层合成和混合式分层画布。项目将成图质量与可直接使用率作为第一优先级，并决定接受生成模型对商品外观产生细微变化。

## 决策

第一版采用端到端 AI 整图生成。商品图片作为参考输入，设计方案作为生成约束，模型直接输出扁平位图。

生成后的图片不保存可编辑文字、图形或商品图层。微调统一采用“圈选区域 + 自然语言指令”的方式调用图片编辑模型，每次成功编辑产生一个新的不可变图片版本。

设计方案在生成前仍为结构化对象，运营可以修改文案、配色、版式意图和图片清单。

## 影响

- 更容易获得整体一致、富有创意的画面。
- 第一版不需要建设专业画布、图层模型和结构化元素编辑器。
- 无法保证商品轮廓、接口、标签和颜色与参考图完全一致。
- 位图内文字不能像文本图层一样精确修改；只能通过 AI 局部重绘尝试调整。
- 每次生成和微调都必须保存所用模型、配置版本、提示词及输入版本，便于追溯和复现。
