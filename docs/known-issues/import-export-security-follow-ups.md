# 导入导出：安全加固待办

当前分支已提供配置 JSON 与项目 ZIP 的导入导出流程，供可信的小型项目进行业务验证。以下问题来自最终安全审查，尚未修复；在完成前，不应将此功能用于不可信来源或超大项目包。

1. ZIP 解压后的 1 GB 限制在解压完成后才再次确认。压缩包元数据可能被伪造，存在解压前耗尽磁盘的风险；需要在解压输出过程中同步限制字节数和文件数。
2. 配置导入未完整恢复提示词模板的默认项语义。导入的自定义默认模板可能与旧默认模板并存，导致运行时继续选用旧模板。
3. 项目导入提交成功后，上传 ZIP 的清理若失败，HTTP 接口可能向客户端返回失败。用户重试时会创建重复项目；成功响应必须与后续清理解耦。
4. 项目包中部分嵌入 JSON 目前只验证 JSON 语法，未验证字段结构。需要为分析结果、设计方向、输出预设快照等增加结构校验。
5. 导入失败可能将命令、数据库或本地路径等底层错误信息返回给客户端。需要改为稳定的用户提示，并只在服务端保留诊断细节。
6. 导出流程未在打包前后执行与导入端一致的 1 GB / 500 MB 限制校验。超大项目可能导出成功却无法导入，应在导出时拒绝并提示。

在此清单关闭前，建议仅使用由本系统生成、来源可信且体积较小的项目 ZIP，并保留数据卷备份。
