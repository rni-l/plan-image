# 使用指南页面设计

## 目标

在“商品图片工作台”中新增独立的“使用指南”页面，帮助首次使用者完成从商品建档到导出成图的完整流程，同时为熟练用户提供模型、Prompt、计费和日志相关的进阶入口。

## 范围

- 在侧栏主导航增加“使用指南”入口，路由为 `/guide`。
- 新页面采用单页、分层阅读结构：先呈现可完成首轮任务的主流程，再呈现按需查阅的进阶配置。
- 页面中的示例优先读取当前本地已有的商品、竞品研究和成图任务；缺少某类数据时使用对应的中性占位示意，不阻塞页面阅读。
- 每张步骤卡提供与内容相关的站内跳转入口。

不包含：引导进度持久化、首次启动弹窗、数据写入、独立帮助中心或外部文档系统。

## 信息架构与界面

页面沿用现有 zinc 色系、220px 侧栏与内容区排版。

### 头部

- 标题“使用指南”，副标题说明该页同时支持首次上手与进阶配置。
- 使用简短的“先完成一轮成图”提示，让新用户先进入主流程。

### 主流程

以连续编号的四步时间线呈现，每步是带真实界面缩略示例的说明卡。

1. **建立商品资料**：新建商品，上传商品图片，补全规格与卖点；按钮跳转至商品库或第一个可用商品的资料页。
2. **完成竞品研究**：上传竞品素材，生成逐图分析并确认综合报告；按钮跳转至第一个具备研究数据的商品研究页，或商品库。
3. **创建并确认成图任务**：选择输出类型、设计方向并编辑方案；按钮跳转至已有任务的对应步骤，或商品的成图任务页。
4. **生成、微调与导出**：查看任务状态、选择结果、局部微调并下载；按钮跳转至任务中心或可生成任务的最终步骤。

缩略示例不保存图片副本。它们以页面内的轻量 UI 复刻显示当前数据中的商品名称、状态、任务步骤或结果缩略图，因而既贴合产品截图观感，也会随本地数据变化。

### 进阶配置

下方使用紧凑的两列知识卡，均有明确说明和直达入口：

- **模型配置**：为竞品分析、方案设计、图片生成与微调选择模型路由；跳转设置中的模型页。
- **输出预设**：设置主图和详情页的尺寸、格式与质量；跳转设置中的输出页。
- **Prompt 管理**：选择、编辑和设定设计方案或图片生成的默认模板；跳转 Prompt 管理。
- **用量与日志**：用计费页观察成本，用日志页定位失败原因；分别跳转至对应页面。

## 数据与降级策略

- 页面并行请求商品列表与任务列表（以及必要的轻量关联数据），选择最近更新且最适合展示的记录。
- 数据加载期间显示与现有页面一致的骨架；请求失败时保留静态说明和所有通用入口，不显示错误阻断内容。
- 若没有商品或任务，主流程的缩略图显示与当前空状态一致的占位，CTA 指向“新建商品”或相关列表页。
- 不新建服务端接口；复用现有产品与任务读取接口，减少耦合。

## 可访问性与交互

- 所有卡片入口均为语义化链接或按钮，具有可见焦点样式。
- 示例缩略图仅为辅助信息，关键步骤由相邻文本完整表达。
- 在小屏下，主流程和进阶卡从两列收为单列，导航不影响内容阅读。

## 验收标准

- 侧栏可进入 `/guide`，激活状态正确。
- 主流程覆盖“商品资料、竞品研究、成图任务、生成与导出”，每一步有说明、示例和可用跳转。
- 示例优先体现当前已有数据，无数据或接口异常时页面仍可正常阅读和跳转。
- 进阶区覆盖模型、输出预设、Prompt、计费、日志，并分别链接到实际存在的页面。
- 新增代码通过现有 TypeScript 构建及相关前端测试。
