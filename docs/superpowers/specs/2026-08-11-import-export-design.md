# 配置与项目导入导出设计

**日期：** 2026-08-11  
**状态：** 已确认，待实施

## 目标

为已部署的商品图片工作台提供跨环境的数据迁移能力：

- 导出和导入环境级配置，但绝不携带 API 密钥或密钥尾号。
- 将一个完整项目（商品、素材、研究、成图任务、图片版本和蒙版）导出为可下载文件，并导入为一个全新的项目。
- 对损坏或恶意包做到导入前拒绝，且导入失败不能留下半成品数据或文件。

## 方案选择

采用 ZIP 归档。

- **配置包：** 纯 JSON，体积小、可审阅。
- **项目包：** ZIP，包含 `manifest.json`、结构化业务数据和素材文件。

没有选择单文件 Base64 JSON：图片会显著膨胀，且容易超过请求与内存限制。也没有选择复制数据库：它会绑定运行目录与环境状态，且不适合安全迁移。

## 数据范围

### 配置包

导出：

- 各供应商的 Base URL（仅适用时）。
- 场景模型路由及默认项。
- 输出预设及默认项。
- 用户自定义提示词模板及默认项。

不导出：

- API 密钥、`keyHint`、密钥文件。
- 内置提示词模板。
- 调用日志、请求日志、用量与计费数据、登录会话。

导入规则：

- 现有 API 密钥和其配置状态保持不变。
- 模型路由与输出预设按导入包替换。
- 内置模板不动；自定义模板按内容去重后导入，以免删除或改写已被历史任务引用的模板。
- 对每个模板类型恢复导入包所指定的默认项；不存在时保留安全的现有默认项。

### 项目包

导出：

- 商品资料、规格、卖点和商品素材。
- 竞品素材、分析版本、逐图分析卡片和综合报告。
- 成图任务、设计方向、方案版本、图片项、完整图片版本与蒙版。
- 被上述任务或图片版本引用的提示词模板，以保留历史可读性。

不导出：

- 认证会话、供应商密钥、密钥尾号。
- 模型调用/HTTP 日志、计费记录。
- 排队或运行中的后台任务；它们在导入后不会自动续跑。

导出任务快照前，必须解析并移除供应商的 `keyHint`，再写入包内数据。

导入规则：

- 总是生成新 ID，并重写项目内所有外键、JSON 中的资产 ID 引用和提示词模板引用。
- 导入创建新项目，绝不覆盖现有项目。
- 已完成图片历史和蒙版完整保留；没有产出文件的运行中占位版本不恢复。
- 导入提示结果需要明确告知不会恢复或自动继续后台任务。

## 归档格式与安全

项目 ZIP 以版本化 `manifest.json` 为入口，声明包类型、格式版本、创建时间、业务数据文件、素材文件相对路径、字节数和 SHA-256 哈希。

服务端需要：

1. 只接受预期的包类型和已支持格式版本。
2. 在解压前校验压缩包大小上限 500 MB。
3. 解压到专用临时目录，拒绝绝对路径、`..` 路径、符号链接和不在白名单目录内的文件。
4. 限制解压后文件总大小为 1 GB，并校验清单列出的每一份文件的路径、大小与 SHA-256。
5. 校验所有表行字段、枚举、JSON 结构和关联完整性后才开始写入。
6. 在单个数据库事务中插入重映射后的数据；数据库提交成功后才将临时素材原子移动到运行时素材目录。
7. 出现任意错误时删除临时目录与已移动文件，返回可理解的错误，且不改变现有数据。

## 服务端设计

新增独立的导入导出服务模块，职责包括：

- 生成与校验 manifest。
- 读取和打包数据与素材。
- ZIP 解包与安全检查。
- ID 映射和引用重写。
- 事务导入、素材原子写入和失败清理。

路由层只处理 HTTP 文件下载/上传：

- 设置资源：配置导出与导入。
- 商品资源：指定项目导出与项目导入。

项目导入静态路径必须注册在 `/:id` 动态商品路由之前。

容器镜像显式安装 `zip` 和 `unzip`，不依赖 Railway 基础镜像的隐式工具。

## 前端设计

- 在设置中新增“数据迁移”页，提供配置下载与上传。配置上传前显示确认提示，说明密钥不在包内且现有密钥不会被修改。
- 商品库标题处新增“导入项目”。上传完成后跳转到新创建的项目。
- 项目工作台标题栏新增“导出项目”，点击后下载 ZIP。
- 导入过程显示进行中状态，失败时展示服务端原因；成功时显示导入项目名称和后台任务不恢复的提示。

## 验收与测试

服务端测试覆盖：

- 配置导出不含 API 密钥或 `keyHint`；配置导入不会修改现有密钥状态。
- 包含素材、蒙版、研究与成图历史的项目导出后再导入，所有关联、文件内容及 SHA-256 校验仍正确，并使用全新项目 ID。
- 损坏 JSON/ZIP、缺失文件、哈希不匹配、非法路径、超限包和关联不完整的包均返回错误，且数据库与运行时文件不发生变化。
