# 领域词汇表

| 术语 | 当前定义 | 状态 |
| --- | --- | --- |
| 竞品图片 | 由运营手动上传、来自 1688 同类商品的主图、详情图或其他商品视觉素材 | 已确认 |
| 商品资料包 | 生成任务使用的自有商品输入，第一版包含商品图片、规格参数和核心卖点；品牌规范可选 | 已确认 |
| 商品 | 商品库中的长期对象，保存自有商品资料，并作为多次成图任务的归属对象 | 已确认 |
| 商品库 | 本地长期保存商品及其资料、任务和版本历史的集合 | 已确认 |
| 行业共性规律 | 从多张竞品图片中归纳出的常见版式、配色、信息层级、卖点表达和场景选择 | 已确认 |
| 差异化机会 | 竞品未充分表达、但可由自有商品资料支持的卖点或视觉方向 | 已确认 |
| 竞品素材集 | 归属于一个商品、由运营上传并长期保存的一组竞品图片 | 已确认 |
| 竞品分析版本 | 基于某一时刻竞品素材集生成的不可变报告版本，可被后续成图任务引用 | 已确认 |
| 逐图分析卡片 | 针对单张竞品图的结构化分析，包含版式、配色、文案、卖点、场景和信息层级 | 已确认 |
| 综合报告 | 汇总多张逐图分析卡片，给出行业共性、差异化机会和设计建议，并保留证据图片引用 | 已确认 |
| 人工修正 | 运营对逐图分析卡片的修改；需与模型原始结果区分，并作为新版综合报告的输入 | 已确认 |
| 设计方案 | 位于竞品分析与成图之间的结构化生成依据，包含文案、配色、版式意图和图片清单 | 已确认 |
| 候选方向 | 系统基于同一分析结果生成的 2–3 个可比较设计方向 | 已确认 |
| 方案确认 | 运营选择候选方向并完成必要编辑后，生成不可变方案版本并进入成图 | 已确认 |
| 图片清单 | 设计方案内可排序的成图项目集合；AI 提供初稿，运营可增删、编辑和排序 | 已确认 |
| 图片项 | 图片清单中的单个输出单元，描述该图的目标、文案、版式意图、素材和生成状态 | 已确认 |
| 批量生成 | 对已确认图片清单中的图片项并行或排队生成；每个图片项独立记录状态和结果 | 已确认 |
| 成图 | 系统根据设计方案和商品素材生成、可作为 PNG/JPG 导出的扁平位图 | 已确认 |
| 成图任务 | 用户可选择主图套图、商品详情页或两者的一次工作流；两种输出共享研究和设计方向，但分别维护图片清单 | 已确认 |
| 商品主图套图 | 面向 1688 商品列表与商品页头部展示的一组图片；AI 推荐清单，运营决定最终张数与组成 | 已确认 |
| 商品详情页 | 由可排序的独立详情模块图组成；可逐模块编辑，并可导出模块图或自动拼接的长图 | 已确认 |
| 详情模块 | 详情页中的单个生成、重试、微调和版本管理单元 | 已确认 |
| 输出预设 | 设置页维护的默认宽高、格式和质量参数；创建任务时可覆盖，任务保存当时配置快照 | 已确认 |
| 微调 | 对纯位图圈选区域后，通过自然语言调用图片编辑模型并产生新版本 | 已确认 |
| 图片版本 | 一次生成或 AI 微调产生的不可变图片状态，可预览、比较和恢复 | 已确认 |
| 商品参考图 | 端到端生成时用于约束商品外观的自有商品图；模型可能对其细节进行重绘 | 已确认 |
| 场景模型路由 | 把一个工作流场景绑定到一个供应商模型的设置；失败时不自动切换 | 已确认 |
| 任务配置快照 | 成图任务创建时复制并固定的模型路由与输出预设 | 已确认 |
| 后台任务 | 持久化执行分析、生成、微调或导出的工作单元，拥有独立状态和错误 | 已确认 |
| 运营人员 | 第一版主要操作者，独立提交任务、确认方案、生成成图并完成微调 | 已确认 |
