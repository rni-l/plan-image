# 领域模型（已确认部分）

## 聚合关系

- 一个“商品”长期保存商品图片、规格参数和核心卖点。
- 一个商品拥有一个可持续补充的“竞品素材集”。
- 竞品素材集可产生多个不可变“竞品分析版本”。
- 一个竞品分析版本包含逐图分析卡片、人工修正和综合报告。
- 一个商品可以创建多个“成图任务”。
- 一个成图任务固定引用一个竞品分析版本，并保存创建时的模型与输出配置快照。
- 成图任务可以包含主图套图、商品详情页或两者。
- 主图套图与详情页共享设计方向，但分别维护可排序图片清单。
- 图片清单由图片项组成；每个图片项独立生成、失败、重试、微调和导出。
- 每个图片项拥有多个不可变图片版本，可比较和恢复。

## 主流程

1. 从商品库选择或创建商品。
2. 上传竞品图片并生成逐图分析卡片。
3. 人工修正卡片，生成带证据引用的综合报告。
4. 创建成图任务，选择主图、详情页或两者。
5. 系统生成 2–3 个设计方向。
6. 运营选择方向并修改文案、配色、版式意图和图片清单。
7. 确认方案后批量生成，图片项独立执行。
8. 逐图主观验收；通过圈选区域和自然语言进行 AI 微调。
9. 导出 PNG/JPG；详情页可导出模块图或自动拼接长图。
