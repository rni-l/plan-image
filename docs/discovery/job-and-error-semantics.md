# 后台任务与错误语义（已确认）

## 统一状态

- 排队中：任务输入与配置快照已经持久化。
- 执行中：后台正在调用模型或执行本地处理。
- 成功：结果已持久化，必要时产生新的业务版本。
- 失败：保留归一化错误与诊断信息，允许手动重试。
- 已取消：任务结果不再自动激活；迟到的外部响应不得覆盖当前结果。

## 操作语义

- 重试：用于处理超时、限流、网络中断等执行失败，沿用同一输入、方案、模型和参数。
- 重新生成：用户对结果不满意时发起新的创意尝试，保留旧图片版本。
- 局部微调：以选定图片版本、圈选遮罩和自然语言指令为输入，成功后产生子版本。

## 失败处理

- 缺少模型、密钥或必需素材时，在提交前阻止任务并给出修复入口。
- 供应商拒绝、超时、限流或网络失败时，不自动换模型；单项失败并允许重试。
- 批量生成中单张失败时，其他图片继续执行。
- 本地服务重启后恢复排队任务；原执行中任务标记为已中断，由用户重试。
- 源文件丢失或损坏时，阻止依赖它的新任务并明确指出缺失资产。

## 结果追溯

每个分析报告、设计方案和图片版本记录输入资产校验值、上游版本、模型场景、供应商、模型、参数、提示词或用户指令、时间及错误。旧结果不受设置页后续修改影响。
