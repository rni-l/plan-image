# 页面结构（已确认）

## 全局导航

- 商品库：浏览和创建商品，是主要入口。
- 任务中心：集中显示正在运行、失败和等待导出的任务。
- 设置：配置模型供应商、场景路由和输出预设。

## 商品工作台

- 商品资料：管理商品图片、规格参数和核心卖点。
- 竞品研究：管理竞品素材、逐图分析、人工修正和综合报告版本。
- 成图任务：查看该商品的任务历史并创建新任务。

## 成图任务步骤

1. 选择主图、详情页或两者，指定竞品分析版本与输出预设。
2. 比较 2–3 个设计方向并选择一个。
3. 编辑文案、配色、版式意图以及主图/详情页图片清单。
4. 确认方案，批量生成，逐图微调、选择最终版本并导出。

步骤状态需持久化，浏览器关闭后可以继续。
